#Контрольные Вопросы

Что такое AJAX и REST API? AJAX — обмен данными с сервером без полной перезагрузки страницы. REST API предоставляет доступ к ресурсам через HTTP.
Чем асинхронный запрос отличается от синхронного? Асинхронный запрос позволяет интерфейсу продолжать работу, пока ожидается ответ.
Что возвращает fetch()? Promise, который разрешается объектом Response после получения ответа.
Для чего нужны async и await? Для удобной работы с асинхронными операциями и ожидания Promise.
Почему следует проверять response.ok? HTTP-ошибки 404 или 500 сами по себе не отклоняют Promise fetch().
Что делает response.json()? Читает тело ответа и преобразует JSON в JavaScript-значение.
Как обработать ошибку сети? Использовать try/catch и вывести понятное сообщение пользователю.
Что такое CORS? Механизм браузера, регулирующий запросы к ресурсам с другого источника.
Чем отличаются GET и POST? GET обычно получают данные, POST отправляет данные на сервер.
Почему нельзя доверять содержимому ответа сервера? Данные могут быть некорректными или небезопасными; их нужно проверять и выводить через textContent.
Как показать индикатор загрузки? Перед запросом показать «Загрузка...», затем заменить текст результатом или сообщением об ошибке.
Для чего нужен AbortController? Он позволяет отменить поддерживающий отмену запрос, например предыдущий запрос поиска.
